# Buildings — Wonders

Built for distinction, XP, or fun. No defense value (or negligible). Typically day 20+ when core defenses done.

**Flags:** `T`=temporary · `I`=impervious · `BP-C/U/R/VR`=blueprint · `UP`=upgradable

## Notes

- All 300 AP wonders require `BP-VR` (very rare blueprint). Don't plan around them unless blueprint confirmed.
- **Reactor** (+500 def, A:5.0) — technically a wonder tier cost/blueprint but def value is real. Treat as priority if BP-VR available.
- Build wonders only after: The Big Rebuild + Underground city complete, water defenses funded, DUV chain maxed.
- **Blue Gold Thermal baths** costs WR ×100 — only viable with full water infrastructure.
